Персональне студентське портфоліо.
Двосторінковий персональний вебсайт-портфоліо студентки факультету прикладної математики. 
Проєкт розроблено з акцентом на семантичну структуру, доступність, адаптивну типографіку та вінтажну естетику 
без використання сторонніх CSS-фреймворків чи JavaScript.

Сайт: https://miarx.github.io/webproject1/

Стек технологій: HTML5, CSS3 (Custom Properties, Flexbox, CSS Grid).

**Адаптивність**
Макет реалізовано за методологією Mobile First. Базові стилі розраховані на мобільні екрани (від 320px), а складніші сітки та 
розташування розгортаються через медіа-запити.

1. Мобільний макет (за замовчуванням, < 768px)
   Навігація прихована всередині семантичного розкривного меню <details class="mobile-menu"> / <summary>. 
   Головний екран (.about) вишикуваний у вертикальну колонку: аватарка по центру зверху, текстовий блок знизу.
   Усі картки дисциплін, захоплень, медіа та спорту розміщуються в 1 колонку 
   (grid-template-columns: repeat(auto-fit, minmax(16rem, 1fr))).
   Форма зворотного зв'язку та таблиця подорожей займають 100% доступної
   ширини екрана (таблиця загорнута в скрол-контейнер).
   Футер вирівняний по центру у вертикальний стовпчик.

2. Планшетний макет (@media (min-width: 768px))
   Збільшуються внутрішні відступи секцій (padding-block: 64px) та контейнерів (padding-inline: 6%, для вузьких — 12%).
   Блок «Про мене» перебудовується у горизонтальний дводіапазонний ряд (flex-direction: row).
   Сітка карток та галерея переформатовуються у 2 колонки залежно від ширини в'юпорту.
   Футер переходить у горизонтальне розташування (space-between).

3. Десктопний макет (@media (min-width: 1024px))
   Повноцінна горизонтальна навігація (.nav-list { display: flex; }), мобільне меню <details> повністю приховується (display: none).
   Сітки секцій (.grid.three, галерея гір та міст) стають триколонковими.
   Контейнери отримують глибші безпечні відступи для фокусування контенту (padding-inline: 8%, .narrow — 16%).
   Типографіка динамічно масштабується до верхніх меж через функцію clamp().

ВИКОРИСТАННЯ ШІ
Під час створення портфоліо я зверталася до ші як до технічного консультанта та практичного довідника.
Ідея візуального стилю сторінки, її естетика вінтажності та концепція подачі матеріалу повністю належать мені,
як і все текстове наповнення — воно складається виключно з реальних автобіографічних фактів, моїх особистих думок, 
навчального та життєвого досвіду.
Штучний інтелект залучався для допомоги в технічній реалізації CSS: підказував синтаксичні рішення для 
точного втілення задуманого стилю (налаштування радіального шуму для фону паперу, формування вінтажних
акцентів і рамок, адаптивна типографіка з clamp та реалізація темної теми). Крім того, я використовувала 
інструмент для перевірки відповідності технічним вимогам завдання — зокрема для пошуку дрібних синтаксичних 
блокерів у W3C-валідаторі, коректного форматування дат за стандартами ISO, розрахунку контрастності кольорів
та додавання правила зменшення руху для доступності.
